# Implementation of a Weighted Dice object in C

When rolling a six-sided die, we know that all faces have an equal probability of landing. That is, each face has a 1/6 probability of being selected.

Weighted dice refer to situations where the probability of a face landing is not equal to the others. Some faces may have a higher or lower probability than 1/6 of being selected.
